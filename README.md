# ColorCart
平涂插画的区域换色工作台。导入PNG/JPEG或加载标注合成性质的演示，建立区域图后单击或Shift多选区域，手动换色、锁色、命名、合并连通区域、撤销重做。色板支持2–8色；项目笔记、复制、PNG/色板/完整ZIP下载和JSON恢复可直接操作。顶部图像准备入口提供原有多帧处理、遮罩、图像变换、比较及导出。

启动：先执行`DOCKER_BUILDKIT=0 docker build -t solo33-colorcart:1.0 .`，再执行`docker compose up -d --no-build`，访问 http://127.0.0.1:18933/ 。数据保存在独立命名卷solo33-colorcart_colorcart-data，停止用`docker compose down`，不删除卷。也可安装requirements后运行`./start.sh`，设置COLORCART_DATA_DIR与PORT使用独立路径/端口。依赖按Python3.11/3.12分支锁定，不含在线服务。当前容器基础为本工作区已有solo32-stencilforge:1.0运行镜像；Dockerfile清空其/app后复制本产品。正式环境Python3.11可使用相同锁定requirements。

输入边长4–2048像素，读入后等比缩小至128×128；透明度低于128视为背景。中值切割分色后按四邻接形成至多64个区域；不足最小面积的碎片透明留空。适合平涂色块，不是精细抠图或色彩管理软件。每次操作按修订号校验，历史保留20步；锁定区域不被手动换色、恢复或合并修改。相邻仅指共享像素边，角点接触不算。原色为建立区域时每区原始RGB中值。所有图片按8位sRGB数值处理，PNG保留alpha，不做ICC保证。演示为程序绘制合成图，并非实拍。

常规预算为单个128像素工作图、64区域和20次历史；通用准备页另有自己的尺寸/容量校验。没有未经测量的大规模性能承诺。ZIP保存当前图、原图、区域/四邻接摘要、色板和完整编辑文档；下载pattern.json可恢复为独立项目。后台计数工具count_backend.py排除前端、文档、脚本、测试和字符串正文。
